# Gym Progress

A mobile-friendly workout tracker for daily training, exercise entries, PRs, volume, and physique check-ins.

## Use

Open the deployed site on your phone. Your workout is saved automatically in the browser after each change.

## Main Flow

1. Open Today Workout.
2. Choose a workout type.
3. Add a common exercise or blank exercise.
4. Fill weight and choose reps from the 1-30 dropdown.
5. Mark PR or failure sets when needed.

## Data

Records are stored locally in the browser. Use Export JSON before changing phones, clearing browser data, or reinstalling the app.
